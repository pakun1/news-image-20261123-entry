## How it works

`main.py` (Python 3.13, standard library only) copies the
pre-rendered `entry.png` (1024×1024) to `/output/entry.png`
(or `$MAKEFUN_OUTPUT_DIR/entry.png` when set). It uses no
network and no randomness, so every run writes identical bytes.
